# 🧾 Expense Tracker (Mini Project)

A simple **command-line-based Expense Tracker** built with **Python** and **Pandas**.  
This project allows you to record, view, filter, update, delete, and analyze your daily expenses easily — with charts for visualization using **Matplotlib**.

---

## 📚 Features

✅ **Add Expense** – Add new expenses with date, category, amount, and notes.  
✅ **View Expenses** – View all recorded expenses in a formatted table.  
✅ **Filter Expenses** – Filter records by category, note, or amount.  
✅ **Modify Expenses** – Update any record by its index number.  
✅ **Delete Expenses** – Remove expenses by index or by category.  
✅ **Total Expenses** – Get a quick total of all your expenses.  
✅ **Data Visualization** – Generate bar and line charts for category-wise and daily trends.  
✅ **Error Handling** – Built-in try/except validation for safe runtime.  

---

## 🧠 Technologies Used

- **Python 3.x**
- **Pandas** – For data storage and manipulation  
- **Matplotlib** – For data visualization  
- **Datetime & OS modules** – For date management and file handling
